# کالیبر — طرح فروشگاه لوازم دیجیتال (فقط UI/UX)

این پروژه **فقط طرح** است — نه یک فروشگاه فانکشنال. هیچ منطق سبد خرید یا فیلتر واقعی در آن پیاده نشده (چون قرار است خودت با HTML/CSS/JS بسازیش). ۵ صفحه‌ی HTML/CSS آماده شده تا:
1. مستقیم در مرورگر ببینیش و طرح رو بررسی کنی
2. با یک پلاگین به فیگما وارد کنی و آزادانه ویرایشش کنی

## صفحات
- `index.html` — صفحه‌ی اصلی
- `shop.html` — لیست محصولات + سایدبار فیلتر
- `product.html` — جزئیات محصول با گالری و جدول مشخصات فنی
- `cart.html` — سبد خرید
- `style-guide.html` — **مهم‌ترین فایل برای فیگما** — تمام رنگ‌ها، تایپوگرافی، دکمه‌ها و کامپوننت‌ها در یک صفحه

## چرا فایل `.fig` نمی‌تونم مستقیم بدم

فرمت `.fig` یک فایل باینری اختصاصی فیگماست و از بیرون (توسط هیچ ابزاری غیر از خود اپ فیگما) قابل تولید نیست. اما یک مسیر عملی و رایگان برای رسیدن به همون نتیجه هست:

### روش پیشنهادی: پلاگین html.to.design
1. این پوشه رو روی یک هاست رایگان بذار — ساده‌ترین راه: پوشه رو داخل یک ریپوی GitHub بریز و از GitHub Pages فعالش کن (رایگان و چند دقیقه‌ای)، یا از Netlify Drop (netlify.com/drop) استفاده کن که فقط با درگ‌ودراپ پوشه یک لینک زنده بهت می‌ده.
2. داخل فیگما پلاگین رایگان **html.to.design** رو نصب کن (از منوی Plugins → Browse plugins → جستجوی html.to.design).
3. لینک هر صفحه (مثلاً لینک `index.html`) رو داخل پلاگین بده — همه‌ی لایه‌ها، متن‌ها، رنگ‌ها و فونت‌ها به‌صورت آبجکت‌های واقعی و قابل‌ویرایش فیگما ساخته می‌شن.
4. صفحه‌ی `style-guide.html` رو هم همین‌طوری وارد کن تا Color Styles و Text Styles آماده داشته باشی — می‌تونی مستقیم از روش تبدیلشون کنی به Local Styles فیگما.

### روش جایگزین (بدون آپلود)
اگر نمی‌خوای آپلود کنی: هر صفحه رو در مرورگر باز کن، Print → Save as PDF بگیر (یا اسکرین‌شات با ابزار فول‌پیج مثل افزونه‌ی GoFullPage)، و PDF/تصویر رو مستقیم داخل فیگما درگ کن؛ پلاگین **PDF to Figma** لایه‌بندی خودکار انجام می‌ده (کیفیت کمی پایین‌تر از html.to.design ولی سریع‌تر).

## سیستم طراحی (برای ساخت دستی در فیگما هم کافیه)

| نقش | مقدار |
|---|---|
| زمینه | `#F3F5F6` |
| سطح کارت‌ها | `#FFFFFF` |
| متن اصلی | `#0E1417` |
| متن کم‌رنگ | `#62707A` |
| تاکید اصلی (نارنجی سیگنال) | `#FF5A1F` |
| متن روی تاکید | `#1A0800` |
| تاکید دوم (آبی مداری) | `#1849D6` |
| خطا/تخفیف | `#D6303F` |
| خط جداکننده | `rgba(14,20,23,.12)` |

فونت نمایشی/متن: **Vazirmatn** (وزن‌های ۴۰۰ تا ۸۰۰) — فونت اعداد/مشخصات فنی: **IBM Plex Mono**
شعاع گوشه: ۴px (کارت‌ها ۶px) — عرض کانتینر: ۱۲۰۰px

عنصر امضادار طراحی: **خط‌کش میلی‌متری** (`.ruler`) به‌عنوان جداکننده‌ی بخش‌ها، و **خطوط راهنمای مشخصات فنی** (`.callout`) روی تصویر هیرو — هر دو برگرفته از زبان بصری دیتاشیت‌های فنی، متناسب با مخاطب فروشگاه لوازم دیجیتال که به مشخصات دقیق اهمیت می‌ده.

## درباره‌ی تصاویر

تصاویر فعلی placeholder از picsum.photos هستن، چون امکان دانلود مستقیم عکس محصول واقعی برای من فراهم نبود. برای تصاویر واقعی محصولات دیجیتال (لپ‌تاپ، هدفون، ساعت هوشمند و...) بهترین منابع رایگان و بدون کپی‌رایت:
- **unsplash.com** — جستجوی `wireless headphones product photo`, `smartwatch white background`, `laptop flatlay`
- **pexels.com** — همون کلیدواژه‌ها، مجوز مشابه
- **pngtree.com / freepik.com** (بخش رایگان) — برای تصاویر با بک‌گراند حذف‌شده (transparent PNG) که برای کارت محصول تمیزترن

اگه بخوای، می‌تونم برات چند نمونه عکس واقعی رو مستقیم توی چت نشون بدم تا از همونجا ذخیره کنی — کافیه بگی.
